# Mascot art

**In use:** `afaque-3d.webp` (full figure) and `afaque-3d-bust.webp` (head and chest) — a 3D illustrated avatar supplied by Afaque, used for the nav profile and the scroll flight. The bottom-right mascot uses the drawn sprite sheets below (its head follows the cursor).

An illustrated likeness of Afaque Jaya, drawn as vector art from his profile
photo (`img/profile/`): black hair with short faded sides and a swept-up top,
thin light-gold aviator-style glasses, thick straight brows, a trimmed beard
that follows the jaw, a beige blazer and an open white collar. Skin, hair,
lip and blazer colours are sampled from the photo.

| File | What it is |
| --- | --- |
| `afaque-directions.webp` | 1080×1080, 3×3 cells of 360×360. Head turned up-left, up, up-right / left, center, right / down-left, down, down-right |
| `afaque-reactions.webp` | 1080×1080, 3×3 cells. blink, heart, sparkle / surprised, wink, bashful / sleepy, dizzy, delighted |
| `afaque-*.svg` | The vector masters the WebPs are rendered from |

The layout follows the sprite format of
[page-mascot](https://github.com/nilbuild/page-mascot) (MIT, © 2026 Kamran
Ahmed). Cell order matches its `DIRECTIONS` and `REACTIONS` arrays, and the
body sits in the same place in all 18 cells, so nothing jumps when the
sheets swap. `js/mascot.js` is a dependency-free port of its React component.

The art is generated by `tools/mascot/build.cjs` (hand-written SVG, no AI
image generation and no third-party artwork). To change colours or features,
edit that script and rebuild:

```bash
npm i --no-save sharp
node tools/mascot/build.cjs
```
